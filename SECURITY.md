# Security policy

EARTH is an active prototype. Please do not disclose vulnerabilities, exposed credentials, or private user data in a public issue.

Report security concerns privately to `earth@nohainc.com` with:

- a concise description of the impact;
- reproducible steps or a minimal proof of concept;
- affected URL, endpoint, or commit; and
- any suggested mitigation.

Please allow time for validation and remediation before public disclosure. Never include passwords, API tokens, database connection strings, or verification links in a report.
